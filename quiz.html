知识点速查

1. 三层架构: Controller(api) -> Service -> Repository -> Storage, 严格单向
2. 人脸管线: 摄像头 -> insightface检测 -> 5点关键点 -> 512维ArcFace嵌入 -> 三处存储
3. 余弦相似度: cos(A,B)=A.B/(|A|x|B|), 对光照缩放免疫, 范围[-1,1]
4. HNSW: 多层图跳跃, O(N)->O(logN), Milvus自动维护
5. 聚类审计: 同号<0.6=脏数据, 异号>0.85=重复注册
6. WebSocket: 持久双向, 心跳ping/pong, 断线重连+HTTP补拉
7. 级联删除: SQLite CASCADE + Milvus手动删 + 磁盘手动删, Service层编排
8. CSV枚举: 数据与代码分离, 改CSV重启即生效
