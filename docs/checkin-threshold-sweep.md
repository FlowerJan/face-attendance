### 代价方向：与审计阈值标定的关键区别

| | 审计（脸库查重） | 签到（1:N 认人） |
|---|---|---|
| 假接受 | 把两个不同的人判为同一人 | **把 A 的脸认成 B，直接给 B 记一条出勤记录** |
| 假拒绝 | 放过真实的重复账号 | 认不出本人（本人重拍一次即可） |
| 判据方向 | 召回=100% + 误报=0 | **假拒绝=0 + 假接受最小** |

> 签到的假接受会写入错误出勤记录，事后要人工核查是谁打的卡；假拒绝只需本人重拍，代价小一个量级。**故判据以「不能漏签」为硬约束，再在解集内把假接受压到最低** —— 与审计标定结构同源，约束方向相反。

## 七、按判据选点

### 阈值

**判据**：硬约束：假拒绝 = 0（一个都不能漏签） + 二级判据：阈值 = 最弱真样本相似度**退一格网格**（上限是单点观测，直接取会站在悬崖边；退一格换取对样本波动的容忍）

| 项 | 值 |
|---|---|
| ★ CHECKIN_THRESHOLD | **0.56** |
| 假拒绝 | 0/11 |
| 假接受 | 0/17 |
| 上限（最弱真样本相似度） | 0.5878 |
| 距上限余量（退一格） | 0.0278 |
| 下界（异人相似度上限） | 0.2099 |
| 距下界余量 | 0.3501 |

> **为什么不是贴着上限取**：上限是最弱真样本这一**单点观测**，只代表「这批样本里最差的一个」，不代表「所有用户的下界」。签到场景恰恰是「换张脸就掉相似度」，直接取上限等于假设未来样本不会更差。退一格换来对样本波动的容忍。

### 余量线

**判据**：硬约束：歧义召回 = 100%（一人多号必须全部告警） + 二级判据：解集内取「到歧义侧间隔 × 到正常侧间隔」最大者（落在歧义余量与正常余量之间的间隙里，兼顾两侧）

| 项 | 值 |
|---|---|
| ★ MARGIN_WARN | **0.27** |
| 歧义召回 | 4/4 |
| 正常签到误告警率 | 0.0% |

**留一法结果：1 / 2 个身份在留出后仍被认出。**

> ⚠ **这个结果必须连同失败项一起读**：留一法没有全通过。
> 失败原因不是代码缺陷，而是**本数据集具备本人跨照片试验的身份太少**（仅 alpha、pro003 两个）。
> 留出 alpha 后，剩余样本的上限升到 pro003 的 0.7298，推导阈值 0.70 ——
> 而 alpha 自己最弱的一张只有 0.5878，于是被漏签。
>
> 这条失败揭示了一个**重要事实**：阈值高度依赖最弱的那个样本。
> 换句话说，「阈值该定多少」这个问题，在只有两个正样本身份时**无法稳定回答** ——
> 任何换一批数据就可能得到不同答案的阈值，都不该被当作标定结果。
> 这正是本次选点采用「上限退一格网格」的理由：在样本稀疏下留出容错空间；
> 而把这条失败明确写出，比藏起来更有价值。

- 底片与抓拍来自同一批采集，未覆盖真实考勤现场的光照/角度/设备差异；现场条件更苛刻时，实际阈值需求可能更高。
- 标定与评估共用同一批试验，阈值由正样本相似度下界推出，故「假拒绝=0」在全量口径上是乐观估计；第九节留一法给出交叉验证结果。
- 负样本中 6 个身份各只有 1 张底片，异人相似度上限（0.2099）仅由少数几对决定；真实场景中学生数量更多，异人上限会更高，届时假接受边界需重新标定。
