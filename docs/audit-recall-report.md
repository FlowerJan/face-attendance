## 四、口径说明（重要，面试请照此说）

- **真实组（1 组 / 共 3 张照片）**：同一位男士的真实照片，逐张录到不同学号；
- **合成组（3 组）**：同一张图做水平翻转 / 提亮增广后录到两个学号，**属构造数据，不是真实采集**；
- **负样本（3 个）**：互不相干的人，各录一张；脚本会先校验它们两两相似度 < 0.40，确认彼此独立后才计入；
- 判定口径：组内出现跨学号高相似度配对，或层次聚类把组内成员聚到同一簇，均计为命中；
- **每个身份只属于一个组**：否则两组里是同一个人，审计判他们重复其实是判对了，却被误算成误报 —— 那是 ground truth 标错，不是审计错了。

## 五、素材限制（必须如实说明）

本机可检出人脸的素材有限：同一人的多张真实照片只有 3 张可用，互不相干的其他身份来自 insightface 自带的合影测试图。因此本评测的规模是「4 组异常 + 3 个负样本」，**不是大规模基准测试**，它的意义在于验证审计逻辑的正确性与阈值设定的有效性。
